# Stakeholder Analysis

## 1. Introduction

The Social Aid Platform connects people who need assistance with people who are willing to provide help.

## 2. Main Stakeholders

| Stakeholder   | Role               | Main Needs                             |
| ------------- | ------------------ | -------------------------------------- |
| Aid Seeker    | Requests help      | Create requests and receive assistance |
| Aid Provider  | Provides help      | Find requests and offer assistance     |
| Administrator | Manages the system | Manage users and requests              |

## 3. Stakeholder Responsibilities

### Aid Seeker

- Create an account.
- Create aid requests.
- View their requests.
- Accept assistance offers.
- Update request status.

### Aid Provider

- Create an account.
- Browse available aid requests.
- Search for suitable requests.
- Offer assistance.
- View assistance status.

### Administrator

- Manage users.
- Manage aid requests.
- Handle reported content.
- Monitor the platform.

## 4. Summary

The main stakeholders are aid seekers, aid providers, and administrators. The system should provide simple features that allow these users to request, provide, and manage social assistance.
