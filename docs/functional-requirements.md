# Functional Requirements

## 1. Introduction

Functional requirements describe what the Social Aid Platform should do.

## 2. User Management

### FR-01: Registration

Users shall be able to create an account.

### FR-02: Login

Users shall be able to log into the system.

### FR-03: Profile

Users shall be able to view and update their profile.

## 3. Aid Requests

### FR-04: Create Aid Request

Aid seekers shall be able to create an aid request with information such as title, description, aid type, and location.

### FR-05: View Aid Requests

Users shall be able to view available aid requests.

### FR-06: Update Aid Request

Aid seekers shall be able to update their own requests.

### FR-07: Delete Aid Request

Aid seekers shall be able to delete or cancel their own requests.

## 4. Finding Aid

### FR-08: Search Requests

Aid providers shall be able to search for available aid requests.

### FR-09: Filter Requests

Aid providers shall be able to filter requests by aid type, location, or status.

## 5. Providing Assistance

### FR-10: Offer Assistance

Aid providers shall be able to offer help for an aid request.

### FR-11: Accept Assistance

Aid seekers shall be able to accept an assistance offer.

### FR-12: Update Status

Users shall be able to update the status of an assistance request.

## 6. Administration

### FR-13: Manage Users

Administrators shall be able to view and manage users.

### FR-14: Manage Requests

Administrators shall be able to view and manage aid requests.

## 7. Notifications

### FR-15: Notifications

The system shall notify users about important updates such as new assistance offers and request status changes.
